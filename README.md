## Overview

LyraMate is a desktop AI assistant that lives as a small, always-on-top animated avatar on your screen. You talk to it via voice (or text...in future), it thinks using a local LLM, and responds with synthesized speech and lip-synced avatar animations. It can also see images (via webcam or drag-and-drop) and execute Python code to automate tasks on your desktop.

Everything runs locally — no cloud APIs, no data leaves your machine.

## Features

- **Voice conversation** — hold Shift+Space (or the mic button) to speak.
- **Vision / Multimodal** — drag-and-drop images, paste from clipboard, or use your webcam. (Works only with multimodal models Gemma 3, Qwen 2.5 VL, etc.)  
- **Desktop automation** — the LLM generates Python code to open browsers, create files, read clipboard, install packages, and more  
- **3D animated avatar** — VRM model with idle, listening, speaking, thinking, and grabbing animation states, smooth transitions, blink sync, and viseme-based lip-sync  
- **Fully offline** — LLM (Ollama), STT (faster-whisper), TTS (Piper) all run locally  
- **Multi-language** — configurable language for both STT and TTS

## ⚠️ Security Notice — AI Code Execution

LyraMate can execute Python code generated by the LLM to perform desktop automation tasks (e.g. creating files, opening the browser, controlling applications). This code runs **with the same privileges as the backend process** — it has full access to your filesystem, network, and installed programs.

**By running LyraMate you accept this risk.** The AI may produce unintended or harmful code. Use at your own discretion.

Recommendations:
- Do **not** expose the API to untrusted networks
- Review the system prompt in `backend/llm/system_prompt.txt` to guide the LLM's behavior
- Monitor the terminal output — executed code and results are logged




## Tech Stack

| Layer | Technology |
|-------|-----------|
| Desktop app | [Tauri 2](https://tauri.app/) (Rust) |

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/andreadx95/LyraMate.git
cd LyraMate
```

### 2. Configure the environment

Copy the example file and edit the values as needed:

```bash
cd backend
cp .env.example .env
```


### 3. Create and activate a Python virtual environment

From `backend/`:

Windows (PowerShell):

```bash
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> If activation is blocked on PowerShell, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` and retry.

### 4. Download the Ollama model

```bash
ollama pull gemma3:12b
```

> Other models work too — set `OLLAMA_MODEL` in `.env`. For vision features, use a multimodal model.

### 5. Download Piper TTS models

Download voice model files (`.onnx` + `.onnx.json`) and place them in `backend/models/piper/`:

Models are available at [Piper Voices](https://github.com/rhasspy/piper/blob/master/VOICES.md)

### 6. Install Frontend dependencies

```bash
cd frontend
npm install
```

## Running

### Backend

```bash
cd backend
.\.venv\Scripts\Activate.ps1
python main.py
```

Linux/macOS:

```bash
cd backend
source .venv/bin/activate
python main.py
```


### Frontend (Tauri)

In a separate terminal:

```bash
cd frontend
npm run tauri dev
```

The avatar window appears as a small borderless, always-on-top widget in the bottom-right corner of your screen.

### Production Build

```bash
cd frontend
npm run tauri build
```

Output: standalone executable in `frontend/src-tauri/target/release/bundle/`



## LyraMate Usage

When you first load the LyraMate frontend, it will prompt you to provide the Backend Endpoint.

It will also request access to your microphone and webcam (webcam is only used with multimodal models).

### How to Interact
Talk: Hold Shift + Space or click the dot on the GUI.

Images: With multimodal models, you can drag & drop images onto Lyra or use Ctrl + V to paste.

Meeting Mode: Ask Lyra to analyze images in real-time through your camera.

## Customization

### Change the avatar model... if you don't like Lyra... 😔

LyraMate loads the VRM avatar from `frontend/public/models/Lyra.vrm`.

You can customize it in two ways:

- Replace `frontend/public/models/Lyra.vrm` with your own `.vrm` file (keeping the same filename).
- Or edit `VRM_MODEL_PATH` in `frontend/src/main.ts` if you want a different filename/path.

After changing the model, restart the frontend:

```bash
cd frontend
npm run tauri dev
```

### Change assistant and user names

Edit `backend/.env` and update:

- `LLM_ASSISTANT_NAME` (assistant name spoken/persona label)
- `LLM_USER_NAME` (your name used in prompt context)

Then restart the backend:

```bash
cd backend
.\.venv\Scripts\Activate.ps1
python main.py
```

Linux/macOS:

```bash
cd backend
source .venv/bin/activate
python main.py
```

### Change the system prompt (Can break everything)

Edit `backend/llm/system_prompt.txt` to customize personality, response style, and behavior.

The placeholders `{assistant_name}`, `{user_name}`, `{language}`, and `{os_context}` are filled from `.env` values at startup.

After editing the prompt, restart the backend so changes are applied.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `❌ Ollama not installed!` | Install Ollama from [ollama.com/download](https://ollama.com/download) |
| `⚠️ Ollama model not found` | Run `ollama pull gemma3:12b` |
| `⚠️ .env file not found` | Copy `.env.example` to `.env` |
| Port already in use | Change `API_PORT` in `.env` |
| CUDA out of memory | Use a smaller Whisper model (`tiny` or `base`) or a smaller LLM |
